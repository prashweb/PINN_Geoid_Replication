# Comprehensive Documentation & Audit Reports

This directory houses the in-depth technical documentation, audits, and reference papers for this replication project.

## Documents
- `PINN_Report.pdf`: Official PDF summary report documenting the entire methodology, empirical comparisons, mathematical variogram formulations, and reproducibility findings.
- `REPLICATION_METHODOLOGY_REPORT.md`: Comprehensive line-by-line codebase mapping, comparative tables, and in-depth forensic analysis.
- `PINN_Paper_Replication_Comprehensive_Audit.md`: Forensic audit classifying all identified differences across 4 distinct categories (stochastic seeds, gridding algorithms, physical loss dynamics, and distance metrics).
- `s00190-025-02017-6.pdf`: Original published article by Jiang et al., *Journal of Geodesy* (2026) 100:4, DOI: [10.1007/s00190-025-02017-6](https://doi.org/10.1007/s00190-025-02017-6).
