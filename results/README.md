# Replication Results & Benchmarks

This directory contains the machine-readable evaluation outputs for the replication.

## Files
- `paper_exact_replication_results.json`:
  Contains complete numerical values comparing our replicated models (DDN and PINN) directly against the published paper's Table 3 (absolute geoid errors on 222 GSVS17 benchmarks) and Table 4 (differential geoid slope RMS across all 12 distance bins covering 24,531 pairs).
